\section{Mathematics}
% ============================================================
Writing math is one of \LaTeX's strongest features.

Inline math: the quadratic formula is $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.

Display equations are typeset in their own numbered block:
\begin{equation}
    f(x) = \int_{-\infty}^{\infty} \hat{f}(\xi)\,e^{2\pi i \xi x}\,d\xi
    \label{eq:fourier}
\end{equation}
Equation~\ref{eq:fourier} is the inverse Fourier transform.

Aligned multi-line equations:
\begin{align}
    \nabla \cdot  \mathbf{E} &= \frac{\rho}{\varepsilon_0} \label{eq:gauss} \\
    \nabla \times \mathbf{B} &= \mu_0 \mathbf{J} + \mu_0\varepsilon_0 \frac{\partial\mathbf{E}}{\partial t} \label{eq:ampere}
\end{align}
Equations~\ref{eq:gauss} and~\ref{eq:ampere} are two of Maxwell's equations.

\section{Flowcharts with TikZ}
% ============================================================
Here is a flowchart drawn entirely with code using the \texttt{TikZ} package.
It demonstrates different node shapes and arrow routing types.

\begin{figure}[h!]
\centering
\begin{tikzpicture}[node distance=2.5cm]
    % Nodes
    \node (start) [startstop] {Start};
    \node (in1)   [io, below of=start, yshift=0.5cm] {Input Data};
    \node (pro1)  [process, below of=in1, yshift=0.5cm] {Process Data};
    \node (dec1)  [decision, below of=pro1, yshift=-0.5cm] {Valid?};
    \node (pro2)  [process, right of=dec1, xshift=3cm] {Fix Data};
    \node (db)    [database, below of=dec1, yshift=-1.2cm] {Save to Database};

    % Arrows
    \draw [arrow] (start) -- (in1);
    \draw [arrow] (in1)   -- (pro1);
    \draw [arrow] (pro1)  -- (dec1);
    
    % Labeled arrows
    \draw [arrow] (dec1) -- node[anchor=east]  {\small Yes} (db);
    \draw [arrow] (dec1) -- node[anchor=south] {\small No}  (pro2);
    
    % Right-angled feedback loop
    \draw [arrow] (pro2) |- (pro1);
    
    % Curved restart arrow
    \draw [arrow] (db) to[bend left=45] node[anchor=east] {\small Restart} (start);
\end{tikzpicture}
\caption{Advanced TikZ flowchart with various shapes and arrow types.}
\label{fig:flowchart}
\end{figure}

\section{Citations}
% ============================================================
Managing references is fully automatic. For example, we might want to cite a famous paper by Einstein~\cite{einstein1905}.
You just need to have the entry in your \texttt{references.bib} file and use \texttt{\textbackslash cite\{key\}}.
\LaTeX\ and \texttt{biblatex} handle all the formatting and bibliography generation.
