# 🚀 LaTeX & Overleaf Masterclass

Welcome to the **LaTeX & Overleaf Masterclass** repository! This repository contains all the source code, diagrams, and templates used during the masterclass to demonstrate the power of LaTeX.

[![Open in Overleaf](https://img.shields.io/badge/Open_in-Overleaf-47A141?logo=overleaf)](https://www.overleaf.com/docs?snip_uri=https://github.com/AbelAnil/LaTex-Help/archive/main.zip)

> **💡 Pro Tip:** Click the green "Open in Overleaf" button above to instantly import this entire repository into your Overleaf account. It will compile automatically, allowing you to view the source code and the generated PDFs side-by-side!

## 📂 What's Included?

This repository contains four main LaTeX files:

1. **`masterclass_presentation.tex`**
   - The actual slide deck used during the masterclass. It's built entirely in LaTeX using the `beamer` package, proving that you don't need PowerPoint to make beautiful presentations!

2. **`diagram_gallery.tex`**
   - A massive cheat sheet containing dozens of vector-perfect diagrams (Flowcharts, System Architectures, Neural Networks, Circuit Schematics) built natively with `TikZ`. You can copy and paste these directly into your own projects.

3. **`advanced_text_formatting.tex`**
   - A showcase of typography features that Microsoft Word simply cannot do. It includes drop caps, text wrapping along mathematical curves, multi-column layouts, and more.

4. **`sample_project.tex`** (Requires `references.bib`)
   - A basic skeleton project showing how to structure a standard report, handle images, mathematical equations, and auto-generate an academic bibliography.

## 🛠️ How to use this repository

**Method 1: The Easy Way (Overleaf)**
1. Click the "Open in Overleaf" badge at the top of this page.
2. Once Overleaf loads, click on any of the `.tex` files in the left sidebar.
3. The PDF will instantly compile on the right side!

**Method 2: Local LaTeX Installation**
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/AbelAnil/LaTex-Help.git
   ```
2. Open any `.tex` file in your preferred LaTeX editor (TeXstudio, VS Code with LaTeX Workshop, etc.).
3. Compile using `pdfLaTeX` (or your preferred engine).
